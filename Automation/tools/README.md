Automation helper scripts (not packages):

- `tools/cardheight.py` — commissioning height helper
- `tools/format_results_xlsx.py` — merge read-height CSVs into a formatted Excel report
  (layout matches `results/Keep/*_Read_Heights_Formatted.xlsx`)
- `tools/experimental/move2.py` — optional reverse read-height characteriser
- `tools/ros2/ros2_bridge.py` — optional ROS 2 telemetry bridge (see tools/ros2/README.txt)
